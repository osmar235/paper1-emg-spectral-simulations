# Human data access policy

The public software examples use simulated data only. No raw or participant-level human EMG/force recordings have been deposited.

The corresponding author may consider reasonable requests for access to study data after confirming that the requested scope is consistent with the original informed consent, applicable ethics approvals, and institutional requirements, and that an appropriate transfer, anonymization/de-identification and data-use agreement can be established. Public release is not guaranteed. Please contact the corresponding author using the contact information in the manuscript.

This is a source-code release, **not** an open human dataset. Software reuse and human data access have separate permissions.
